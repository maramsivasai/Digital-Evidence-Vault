# Digital Evidence Vault

A secure web application for managing digital evidence, verifying evidence integrity, and maintaining chain-of-custody records.

## Technology Stack

- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MongoDB
- Authentication: JWT
- Password Security: BCrypt
- File Encryption: AES-256
- Integrity Verification: SHA-256
- Version Control: Git and GitHub

## Main Features

- User authentication and role-based access control
- Digital evidence upload and secure storage
- Evidence search and retrieval
- Evidence integrity verification
- Chain-of-custody management
- Audit logging
- Case management

## Project Structure

- `frontend/` — React user interface
- `backend/` — Express API and evidence-management logic
- `docs/` — Project documentation and diagrams
- `scripts/` — Development and maintenance scripts

## Security

Evidence files must be encrypted before storage. Encryption keys and environment secrets must never be committed to the repository.
